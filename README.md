# SpiceRoute Full Stack Food Delivery Project

A modern React + Tailwind food delivery homepage with a Node.js, Express and MongoDB backend.

## Frontend Run

```bash
cd frontend
npm install
npm run dev
```

## Backend Run

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

MongoDB should be running locally or you can add a MongoDB Atlas URL in `backend/.env`.
